## 📋 Descrição

Recrie o clássico jogo Asteroids em Python com suporte a dois jogadores, detecção de colisão e mecânicas de gameplay autênticas.

## 🎮 Features

- ✨ Gameplay clássico de Asteroids
- 👥 Modo para 2 jogadores
- 💥 Sistema de colisão com círculos
- 🎯 Pontuação e sistema de vidas
- 🎨 Gráficos simples e diretos

## 🛠️ Tecnologias

- **Python 3.8+**
- **Pygame** - Biblioteca para desenvolvimento de jogos
- **JSON** - Persistência de estado do jogo

## 📦 Instalação

### Pré-requisitos
- Python 3.8 ou superior
- pip

### Setup

```bash
# Clone o repositório
git clone <seu-repositorio>
cd asteroids

# Crie um ambiente virtual
python -m venv .venv
source .venv/bin/activate  # No Windows: .venv\Scripts\activate

# Instale as dependências
pip install -r requirements.txt
